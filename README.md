## About

I'm a full-stack engineer who ships to production and stays for what happens next. I build and run a B2B SaaS platform end to end: TypeScript backend, React frontend, Postgres, Stripe billing, and the servers and DNS underneath it on Cloudflare and AWS. The bugs I like most are the ones that only show up in production, and I like proving the fix there.

I study Software Engineering at FIAP (graduating Dec 2027) and co-founded [Phasex-arch](https://github.com/Phasex-arch), where we build our team projects. Outside work I go deeper into systems topics: operating systems, networking, database internals and security.
